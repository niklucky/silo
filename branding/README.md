# Silo branding

Selected FIELD symbol and matte-metal app icons, prepared for later use. No assets have been applied to the app. No wordmark or font has been selected.

## Logo symbol

- `logo/silo-sign.svg`: default black, editable vector master.
- `logo/silo-sign-black.svg` / `logo/silo-sign-white.svg`: solid black and white variants on transparent backgrounds.
- `logo/silo-sign-black.png` / `logo/silo-sign-white.png`: transparent PNG exports, 2048 pixels wide.

The vector is a clean reconstruction of the approved bold FIELD symbol: a thick rounded rectangular frame and two six-spoke asterisks. It contains paths only, with no fonts, embedded raster images, or background. Preserve its aspect ratio when resizing.

## App icons

- `app-icons/black/`: selected matte-silver symbol on a black background.
- `app-icons/white/`: selected matte-graphite symbol on a white background.

Each directory contains the unchanged selected `master.png` (1254 × 1254) and square PNG exports at 16, 32, 64, 128, 256, 512, and 1024 pixels. Variant names refer to the **background**, not the symbol color. These images contain no title. Platform-specific packaging can be added when integrating them.

## Web favicon

- `favicon/favicon.svg`: transparent, square SVG; black symbol in light mode and white in dark mode.
- `favicon/favicon.ico`: 16, 32, and 48 pixel entries for browser fallback.
- `favicon/favicon-16.png`, `favicon/favicon-32.png`, `favicon/favicon-48.png`: individual raster alternatives.

Favicons use the flat symbol for small-size legibility. Raster fallbacks place it on a white tile so it remains visible in both browser themes. No HTML, manifest, or app configuration was changed.

## Saved vault

`archive/vault/vault-03.png` preserves the standalone realistic vault recreation requested for another use. `archive/vault/original-concept-sheet.png` preserves the exact original concept image, including its surrounding exploration. These are archived references, not the selected app identity.

The matte app icons and vault were created using built-in Imagegen. Their original prompt set is retained at `archive/generation-prompts.md`. Wordmark explorations are not part of this selected asset package.
